# Алгоритм Пик!

Весёлая детская мини-игра на чистых HTML, CSS и JavaScript. Никаких зависимостей и сборки не требуется.

## Играть онлайн

[Открыть «Алгоритм Пик!»](https://tm2sh.github.io/algorithm-pik/)

## Запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в папке проекта.

Например:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Игра не обращается к внешним сервисам и полностью работает как статический сайт.
