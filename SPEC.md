# Спецификация: «Алгоритм Пик!»

## Цель

Сделать маленькую весёлую браузерную игру для детей, которую можно открыть локально или опубликовать на GitHub Pages без сборки и зависимостей.

## Пользовательский сценарий

1. При открытии страницы видны заголовок «Алгоритм Пик!» и красная кнопка «Нажми».
2. Нажатие на кнопку воспроизводит короткий звук «пик».
3. После звука открывается сверстанное модальное окно с вопросом и кнопками «Да» и «Нет».
4. Нажатие на любую из двух кнопок воспроизводит звук «пик» и показывает крупную надпись «Пик!».
5. После короткой анимации интерфейс автоматически возвращается к начальному экрану.

## Требования к интерфейсу

- Игра занимает весь экран, основной элемент находится по центру.
- Дизайн яркий, дружелюбный и хорошо читаемый на телефоне и компьютере.
- Модальное окно реализовано HTML/CSS, без `alert`, `confirm` или сторонних библиотек.
- Кнопки доступны с клавиатуры и имеют заметные состояния наведения и фокуса.
- При включенном `prefers-reduced-motion` интенсивные анимации отключаются.

## Технические ограничения

- Только HTML, CSS и JavaScript.
- Без React, сборщика, внешних шрифтов и сетевых ресурсов.
- Звук генерируется через Web Audio API и не требует аудиофайла.
- Проект должен работать как статический сайт на GitHub Pages.

## Критерии приёмки

- `index.html` открывается напрямую и через статический HTTP-сервер.
- Каждый полный цикл заканчивается возвратом к стартовому экрану.
- Кнопки «Да» и «Нет» запускают одинаковый корректный финал.
- Повторные быстрые нажатия не создают несколько модальных окон или таймеров.
- В консоли браузера нет ошибок во время основного сценария.
